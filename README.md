🌐 **Live URL**: [https://johntechbcloud.github.io/technowera/](https://johntechbcloud.github.io/technowera/)

## 🌟 Key Features

- **Execution-Led AI & Agentic Automation**: Multi-Agent workflow orchestration (AutoGen/LangGraph), Enterprise Copilots, and ITSM autonomous agents.
- **AI-Ready Data Foundations & Fabric**: Unified Lakehouse architecture, real-time streaming pipelines, vector databases, and zero-copy data sharing.
- **Cloud Modernization & Multi-Cloud FinOps**: Azure/AWS/GCP migration patterns, zero-trust cloud security, and AI-driven cost optimization.
- **Interactive Agent Simulator**: Real-time simulation of autonomous AI agents executing enterprise workflows (Security Triage, Invoice Reconciliation, Data Pipelines).
- **Interactive Enterprise ROI Calculator**: Real-time ROI & cost savings estimator powered by dynamic calculation algorithms and confetti celebratory feedback.
- **Pre-Built Solution Accelerators**: Library of 65+ production-ready frameworks (e.g., *AgenticOps Hub™*, *FabricData Sphere™*, *CloudFinOps Guard™*).
- **Dynamic Dark/Light Theme**: Theme switcher built with CSS variable tokens and seamless Tailwind utility integration.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/johntechbcloud/technowera.git
   cd technowera
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Local Development Server**:
   ```bash
   npm run dev
   ```

4. **Access the Application**:
   Open your browser and navigate to `http://localhost:5173`.

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the Vite development server with Hot Module Replacement (HMR).
- `npm run build`: Compiles and bundles production-ready assets into the `dist/` folder.
- `npm run preview`: Locally previews the production build output.
